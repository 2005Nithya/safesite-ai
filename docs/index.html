About SafeSite AI

SafeSite AI is an advanced computer vision system designed to enhance safety monitoring on construction sites. Using state-of-the-art YOLOv8 object detection, it identifies safety hazards in real-time from video feeds and static images.

Key Features

📹 Real-time Detection

Process live video feeds and detect safety violations instantly

🤖 AI-Powered

YOLOv8 neural network for accurate object detection and classification

📊 Analytics Dashboard

Track safety metrics and historical data with interactive visualizations

🎥 Multi-Source Support

Support for CCTV feeds, video files, and image uploads

🔐 User Management

Secure authentication and role-based access control

Ready for Netlify and Render deployment

Getting Started

To set up and run SafeSite AI locally:

# Clone the repository
git clone https://github.com/2005Nithya/safesite-ai.git
cd safesite-ai

# Create virtual environment
python -m venv .venv

# Activate virtual environment
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the application
python app.py

Deployment

SafeSite AI is configured for easy deployment on multiple platforms:

  • Netlify: See netlify.toml for configuration
  • Render: See render.yaml for deployment settings
  • Docker: Dockerfile included for containerization
